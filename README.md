# ROYAL TOOTH — магазин (Telegram Mini App)

Бесплатно: GitHub Pages + Google Apps Script + Google-таблица.

Файлы: `index.html` (витрина), `catalog.json` (товары), `img/` (фото), `apps-script/Code.gs` (приём заказов).
Пока `APPS_URL` в `index.html` пуст, заказ уходит сообщением в Telegram `@RoyalTooth`.
